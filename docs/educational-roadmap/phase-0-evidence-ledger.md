# Pre-Compiled Trick Index

## Index 01 — Secondary Constraint Flag

**Trap:** A primary inequality is followed by a smaller sign/domain condition that changes which branch is valid.

**Defense:**
1. Compute the primary relation.
2. STOP before selecting an answer.
3. Re-scan the entire prompt for terminal sign, domain, unit, or positivity constraints.
4. Substitute only after all constraints are assembled.

## Index 02 — Discriminant Zero Boundary

**Trap:** The prompt says a quadratic has exactly one distinct real solution.

**Defense:** Treat “one distinct real solution” / “touches the x-axis once” as a discriminant condition: b² - 4ac = 0. Then verify the requested quantity and every stated sign restriction.

## Index 03 — Radical Return-Loop

**Trap:** Squaring a radical equation creates an algebraic candidate that was not valid in the original equation.

**Defense:** Every candidate generated by squaring must be substituted back into the original unsquared equation before acceptance.

## Index 04 — Target/Work Mismatch

**Trap:** Solving for a variable when the prompt asks for an expression, count, rate, or transformed quantity.

**Defense:** Circle the exact requested output before doing algebra; do not stop when an intermediate variable is obtained.

## Evidence discipline

A source-dependent rule must be classified as one of:

- **Verified:** directly supported by the current institutional source.
- **Planned:** a roadmap choice, not an institutional requirement.
- **Provisional:** plausible schedule/sequence awaiting advisor or degree-audit confirmation.
- **Unsupported:** remove it from the roadmap until evidence exists.
- **Superseded:** retained only for audit history; not executable.

Do not promote a strategic preference into a university rule without evidence.
